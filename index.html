Signiverse

Challenge

Deaf and Hard-of-Hearing children in Jordan have limited access to interactive Jordanian Sign Language learning tools.
Most existing independent Jordanian Sign Language learning methods lack engagement and do not provide immediate feedback, making independent practice difficult for deaf children.

Our solution

Develop SigniVerse, an AI-powered serious mobile game that uses real-time sign recognition and instant feedback to help children learn Jordanian Sign Language through interactive activities and independent practice.

System Architecture

How Signiverse processes real-time sign recognition behind the scenes

1
Launch App

Open the Signiverse application.

2
Select Game

Choose a minigame and start playing.

3
Camera Initialization

The live device camera and sign target panel open automatically.

4
Landmark Tracking

Integrated MediaPipe plugin scans hand & body landmarks in real-time.

5
API Request

Sends processed sequence data as JSON request to FastAPI hosted on Render.

6
Prediction Output

FastAPI backend processes the sequence and returns the predicted sign.

7
Verification & Gamification Loop
Match Correct ✅

Player receives instant correct sign feedback, progresses in the game, and gets stars.

Mismatch ❌

Player gets feedback to try again and cannot progress until performed correctly.
